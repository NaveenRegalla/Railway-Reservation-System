# Railway Reservation System

A menu-driven railway reservation application developed using the C programming language.

## Features

- User sign-up and sign-in
- Display train and seat information
- Reserve railway tickets
- Cancel reserved tickets
- View booking details
- File-based data storage
- Passenger management using a singly linked list

## Technologies Used

- C Programming
- Structures and pointers
- Dynamic memory allocation
- Singly linked lists
- File handling
- Makefile and GCC

## Build and Run

Requirements: GCC and GNU Make on Linux or WSL Ubuntu.

```bash
make
./train
```

## Purpose

This project demonstrates modular C programming, linked-list operations, dynamic memory allocation, and file handling through a railway reservation application.
